# adventures Spec（ユーザー管理機能）  

作成者：ブタメロン  
作成日：2026/6/20  

# ■ ディレクトリ  

adventures ユーザー管理モジュール  

# ■ 目的  

ギルドメンバーの管理を行うモジュール

主な用途  

- アプリケーションユーザー管理  

# ■ 機能概要  

- 初回ユーザー設定機能
- ユーザープロフィール編集機能  

# ■ 関連テーブル一覧  

- users // 認証基盤
- adventures // 公開アプリケーションユーザーテーブル  
- adventures_setting //　ユーザー設定テーブル
- user_identity // 本人情報 公開初期では作成しません
- adventures_skills //　スキルタグ中間テーブル。スキル毎の経験値もここに保持
- skills // スキルタグ一覧


# ■ モジュール概要  

- ユーザーの初回設定およびユーザー編集を行う
- ユーザーは初回ログイン時、強制的に設定を求められる。（anonymousは存在しない）
- adventuresはauth.idの他、不変のvertual_nameを保持する。

# ■ skills table specs
- 親skill,子skillを明確に分離する。
- UX上の成約として、親、子まで。孫は持たない（今後拡張の可能性あり。）
- 階層NOを保持する。親：１,子：２として、分岐する。（今後拡張する場合は孫：３を準備する）
