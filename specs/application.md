作成者：ブタメロン  
作成日：2026/6/20  

# ■ 目的  

冒険者が集まり、  
交流し、  
信頼関係を構築できる  
コミュニティ基盤を構築する。  

将来的には、その信頼関係を元にした  
仮想経済圏の形成を目指すアプリケーション  

仕事マッチングなどが将来機能となれば良いが、MVP段階では高品質でセキュアな掲示板機能のみ保持する。

- 与信情報機能


## ＞４次フェーズ（取引基盤）  
一般的な販売管理機能の、仕入以外の機能は必要となりそうですね。
- クエスト機能 // 金額指定or見積依頼の場合もあり
- 応募機能　// 要見積作成
- 見積作成機能 // 応募データに紐づけ。クエスト側で金額指定の場合は金額は以内である
　　追加見積にも対応する。
　　追加見積が前提となり、最初の見積が完遂出来ない場合は契約不履行を大きく表示。
- 交渉 // 
- 契約成立 // 見積承認（つまり受注）
- 契約書管理機能　// 
- 作業報告 // 将来的な仲裁の場合の証明に使用したい。
- 納品機能 // 売上・仕入（ここで審査などの仕組みは課題感ありあり）
- 請求機能 // 見積作成前提で請求。
- 決済機能 // 支払、回収
- 請求証明書ギルド本部送付機能 // 揉めた時用

## ＞５次フェーズ（経済基盤）
- 信頼機能　// 契約終了後フィードバック機能
- 経験値機能 // フィードバックを元に計算
- ランク機能 // 個人・パーティ・法人
- パーティ信頼機能 // 個人経験値などで計算
- 法人信頼機能 // 経験値などで計算
- アチーブメント機能 // ゲーミング性
- 称号機能 // 個人信用基盤
- レビュー履歴 // 何者か調べるぜ

## ＞６次フェーズ
- ポートフォリオ管理
- レイドクエスト機能 // 複数個人、複数パーティ、複数法人でプロジェクト受ける機能
- 業種別ランキング機能
- 異議申し立て // 納品物を受け取ってくれない場合
- 仲裁機能 // 基本的に運営は平等だが、弁護士的な機能も必要となる。  
　　　　　　ただし、弁護士は運営が匿名案件で提示する。
