# search Spec（検索機能）

作成者：ブタメロン
作成日：2026/6/28

# ■ ディレクトリ

検索モジュール

# ■ 目的

ユーザーおよび掲示板を検索するための共通モジュール。

本モジュールはデータを保持せず、既存モジュールの情報を検索する役割を担う。

# ■ 主な用途

* ユーザー検索。
* 掲示板検索。
* 検索条件による絞り込み。
* 並び替え。

# ■ 基本仕様

* 検索専用テーブルは保持しない。
* 各モジュールのデータを横断して検索する。
* 検索条件未指定の場合は新着順を表示する。
* 検索結果はページングに対応する。
* 将来的な全文検索への拡張を考慮する。

# ■ 機能概要

## ユーザー検索

検索条件例

* ユーザー名。
* 職業。
* スキル。
* 地域。
* オンライン状態。
* 募集中。

並び替え例

* おすすめ順。
* 新着順。
* 最終ログイン順。
* 評価順。

## 掲示板検索

検索条件例

* タイトル。
* 本文。
* カテゴリ。
* タグ。
* 募集人数。
* 地域。
* 作成者。

並び替え例

* おすすめ順。
* 新着順。
* 更新順。
* 人気順。

# ■ 将来拡張予定

* 検索履歴。
* 保存済み検索条件。
* 人気検索ワード。
* AIによる検索条件提案。
* AIによるおすすめ検索結果。
* 全文検索対応。

# ■ 関連テーブル一覧

本モジュール専用テーブルは保持しない。

利用テーブル例

* users
* profiles
* jobs
* skills
* mid_users_jobs
* mid_users_skills
* boards
* board_tags

# ■ モジュール概要

* ユーザー検索および掲示板検索を提供する。
* 検索専用データは保持しない。
* 各モジュールのデータを検索条件に応じて取得する。
* 将来的な検索機能拡張を考慮した共通モジュールとする。
