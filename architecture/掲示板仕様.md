# Square Specs（掲示板機能）

※ほとんど落書きですが仕様書です

# ■ ディレクトリ

Square 掲示板機能モジュール

# ■ 目的

ギルドメンバーがコミュニケーションを行うための掲示板機能を提供する。  

主な用途  

- 雑談
- 技術質問
- ナレッジ共有
- 人材・案件募集
- 運営告知

# ■ 機能概要
- markdown記法をベースにしたリッチUI
- XSS対策
- 不適切発言チェック（NGワード）
- 不適切発言モデレーション
- 表示制御（不適切レベルで切り分け：UI優先）
- いいね機能
- 通報機能
- userprofileリンク機能
- タグ付け機能

# ■ モジュール概要

-掲示板投稿およびコメント投稿はサーバーコンポーネントを中心に処理を行う。 
-元投稿削除時は"内容が削除されています"に置き換える。元投稿者などは消えるが、  
 削除内容に対してコメントは紐づいたままとする

セキュリティに関する仕様は以下の通り：

- 投稿データ受信
- NGワードチェック
- サニタイズ処理
- DB保存
- AIモデレーション処理
- ステータス更新
- UI表示制御
- 通報・監視連携

# ■ 投稿データ処理フロー

- 該当処理は、以下のケースで実施する
1.掲示板投稿
2.掲示板編集
3.コメント掲載
4.コメント編集

モデレーションフローを記載する。  
言語化すると、登録はモデレーションなしで実施し、登録終了後にOpenAI Moderation APIでステータスを変更する。

```flow
[投稿]
↓
ng_filter（NGワードフィルタ）
↓
Sanitize (markdown攻撃回避)
↓
DB保存（pending）
↓
OpenAI Moderation API (NG投稿フィルタ)
↓
状態更新
↓
UIフィルタ (バッド)
↓
Report蓄積　
↓
自動フラグ
```
